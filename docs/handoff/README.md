# docs/handoff – физическая граница волны

Волна ЗАКРЫВАЕТСЯ записью `<волна>.md` в эту папку, следующая ОТКРЫВАЕТСЯ в свежей сессии,
первое чтение которой – этот файл и `docs/CURRENT.md`. Продолжать старую сессию нельзя: один
Read стоит пару тысяч токенов, прогрев длинной истории стоит всю историю
(закон владельца 29.09.2026, перенесён из Ties Break).

Шаблон – коротко, фактами, без нарратива:

```markdown
# Handoff – Волна N: SPEC-NN <название> (<дата>)

## Сделано
- <одна строка на вещь, с sha коммита>

## Открыто
- <одна строка на хвост, где он записан (спека §, решение, CURRENT)>

## Файлы
- <путь> – <полстроки зачем>

## Гейты
- test.sh: <вердикт> (<лог>) · unity-tests.sh: <вердикт> · build.sh: <размер, время> · паритет: <max |Δ|>

## Бюджет
- агентов: N · ходов всего: M · сверх бюджета: <кто и почему>
```

Файл отвечает на три вопроса свежей сессии: что СДЕЛАНО, что ОТКРЫТО, куда НЕ лезть заново.
