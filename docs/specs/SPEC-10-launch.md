### 1 · Листинг

Название (O-06), короткое описание ≤ 80 знаков, полное ≤ 4000 (по мотивам README 2D: физика дрифта,
комбо, 6 локаций × 2, 8 машин, гараж, ачивки, без рекламы, offline), ключевые слова категории Racing;
скриншоты – сценарии: старт на cafe-marble, дрифт с неоном ночью (green-study), near-miss ножей
(steel-kitchen), результат с NEW RECORD, гараж, модификация, миникарта/HUD, Zen; трейлер – 30 с из
`capture-sequence` (dev-сборка на ПК 1080p60) + титры; без музыки (O-03) или CC0-трек с указанием.

### 3 · Страницы 2D-игры

Баннер/абзац в README и на меню веб-игры (ссылка в стор), devlog-посты на трёх платформах по
плейбукам; QR/ссылка – через PR в DesktopDrift по его правилам (SW-кэш, тесты) – делает билдер 2D.

### 4 · Rollout

Поэтапный выпуск, мониторинг крашей 48 ч между ступенями, hotfix-процедура (версия code+1, тег).
